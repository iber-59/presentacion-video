¿Qué es Elige Vivir?

Elige Vivir es un proyecto educativo creado por estudiantes para promover la prevención del consumo de sustancias controladas, el acceso a información confiable y las decisiones saludables.

Decir NO a las drogas es decir SÍ a tus sueños, a tu salud y a los que te quieren.

Nuestros objetivos

🎯 Informar

Compartir información y contactos de ayuda para que cualquier persona sepa dónde acudir.

💪 Prevenir

Fomentar que cada persona tome sus propias decisiones y aprenda a decir NO ante la presión.

🤝 Acompañar

Recordar que hablar con alguien de confianza y pedir apoyo es una muestra de valentía.

Conclusión

Con este proyecto comprendimos que una página web se construye en tres capas que trabajan juntas: HTML para la estructura, CSS para el diseño y JavaScript para la funcionalidad. Las etiquetas aprendidas nos permitieron crear un sitio ordenado, accesible y con herramientas interactivas. Las etiquetas semánticas como <header>, <nav>, <main>, <section> y <footer> dieron orden al código; con <form>, <label>, <input> y <button> aprendimos a recoger datos, y con <table> a mostrarlos con claridad. Los atributos id y class fueron el puente entre las tres capas, porque permiten que el CSS aplique estilos y que el JavaScript modifique cada elemento. Esto se vio en el registro de personas, donde validamos datos, evitamos carnets repetidos y los guardamos con localStorage, y en los consejos del día, donde elegimos contenido al azar y lo animamos para mejorar la experiencia del usuario.

También aprendimos buenas prácticas como la accesibilidad, la adaptación al celular y los mensajes de error en tiempo real, y reconocimos las limitaciones del proyecto: al guardar los datos solo en el navegador, la información no se comparte entre dispositivos, y un sistema real necesitaría un servidor y medidas de seguridad. Finalmente, el trabajo nos mostró que la tecnología puede ponerse al servicio de un tema con valor social: la prevención y el cuidado de la salud. Los consejos sobre hacer deporte, hablar con alguien de confianza y decir no a la presión demuestran que una página web no es solo código, sino también una herramienta para informar y promover decisiones saludables, especialmente entre los jóvenes.
